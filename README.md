### 安装与升级

1. 解压安装包。
2. Chrome 打开 `chrome://extensions`，开启开发者模式。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。
4. 刷新要使用的网页，再主动开启记录。

升级时先停止记录，将新版文件替换到原扩展目录，再点击扩展卡片的重新加载。不要卸载或清空浏览器数据，以免丢失本地历史。
